# 家計簿アプリ（PWA版）導入ガイド

スマホ・PCに「アプリ」としてインストールして使える家計簿です。
データは **いつもの「家計簿」スプレッドシート** にそのまま保存されます。アプリで記録すると、その月のシート（11月・12月…）の右側の表に、今までと同じ書き方（日付・「支出・paypay」・内容・金額）で1行追加されます。左側の集計表もいつもどおり計算されます。どの端末で入力しても同じ内容になります。
claude.ai へのログインは不要です。

```
kakeibo-app/
├── index.html              アプリ本体
├── manifest.webmanifest    インストール用の設定
├── sw.js                   オフラインでも開けるようにする仕組み
├── icons/                  アプリのアイコン
└── gas/
    └── Code.gs             スプシを読み書きするプログラム（Apps Script）
```

導入は「① データの保存先を作る」→「② アプリを公開する」→「③ 各端末にインストール」の順に進めます。①と②は最初の1回だけです。

---

## ① スプレッドシートにプログラムを追加する（Apps Script）

1. いつもの「家計簿」スプレッドシートを開きます。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 左の「ファイル」の「＋」→「スクリプト」で新しいファイルを作り、名前を `KakeiboApi` にします。その中身を全部消して `gas/Code.gs` の中身を貼り付け、💾（保存）を押します。
   - **最初からある `コード.gs` は消したり上書きしたりしないでください。** スプシの計算式で使っている `SHEETNAME()` などの関数が入っています。
4. 上部の関数の選択欄で `setup` を選んで「実行」を押します。
   - 初回は「承認が必要です」と出ます。「権限を確認」→ 自分のアカウントを選びます。
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」→「許可」と進みます。自分で作ったスクリプトなので問題ありません。
5. 下の「実行ログ」に次の2行が出れば成功です。キーはメモしておきます。
   - `読み込めた記録：196件（6月・7月・…・11月）`
   - `アプリに入力するキー：xxxxxxxx`
6. 右上の「デプロイ」→「新しいデプロイ」を選びます。
   - 歯車アイコン →「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」は **自分** にします。
   - 「アクセスできるユーザー」は **全員** にします。
   - 「デプロイ」を押すと「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）が出るので、コピーしておきます。

> 「アクセスできるユーザー：全員」にしても、キーを知らない人はデータを読み書きできません。キーは人に教えないでください。
> もしキーを知られてしまったら、Apps Script で `resetKey` を実行すると新しいキーに変わります。

### スプシ側での動き
- **追加**：その月のシートの右側の表（I〜L 列）の、一番下の記録の次の行に書き込みます。
- **月の新規作成**：その月のシートがまだ無ければ、「基盤」シートを複製して「2026年12月」のような **年つきの名前** で作ります。置く場所はいつもどおり、新しい月が左です。
  - 年つきの名前でも左側の集計表が動くように、複製したシートの計算式を自動で直します。月の数字（A1）と、残高の「先月から引き継ぐ」式で先月のシートを直接指すようにしています。
- **編集・削除**：I〜L 列だけを書き換えます。削除したときは、下の記録を1行ずつ上に詰めます。左側の集計表（C〜G 列）や行そのものには触りません。
- **直接の書き込み**：スプシに直接書き込んだ記録も、アプリに反映されます。アプリ側では ⟳ を押すか、1分ほど待ってください。
- **同じ行を同時に変えたとき**：アプリで編集しようとした行がスプシ側で変わっていた場合は、上書きせずに読み直します。

### 年の扱い
- **今あるシート**：今までの「6月」〜「11月」のシートは、名前を変えずにそのまま 2026年の分として読み込みます。
- **これから作るシート**：アプリが作るシートは「2026年12月」「2027年1月」…と年が入るので、来年の6月になっても今年の「6月」とかぶりません。古いシートを消したり移したりしなくても、ずっと使い続けられます。
- **自分でシートを作るとき**：「2027年3月」のように年つきの名前にしてください。ただし、自分で「基盤」を複製した場合は、左側の残高の計算式は自動では直りません。新しい月のシートはアプリでその月の最初の記録をすると自動で作られるので、基本はアプリに任せるのがおすすめです。

### 気をつけること
- **同じ口座の「支出・収入」が1行にある記録**：8/11の牛丼のような記録は、アプリでは支出と収入の2件として表示されます。アプリで編集すると、1行1件の書き方に直ります。

## ② アプリを公開する（GitHub Pages・無料）

1. GitHub で新しいリポジトリを作ります（例：`kakeibo`）。公開設定は Public のままで大丈夫です。アプリの画面だけが公開され、家計簿のデータやキーは入っていません。
2. リポジトリの「Add file」→「Upload files」で、`gas` フォルダ以外のファイル（`index.html`・`manifest.webmanifest`・`sw.js`・`icons` フォルダ）をまとめてドラッグして、「Commit changes」を押します。
3. 「Settings」→「Pages」を開き、「Branch」を `main`・`/ (root)` にして「Save」を押します。
4. 1〜2分待つと `https://（ユーザー名）.github.io/kakeibo/` でアプリが開けるようになります。

## ③ 各端末にインストールする

最初に開いたとき「データの保存先に接続」画面が出るので、①でメモした **ウェブアプリの URL** と **キー** を入力して「接続する」を押します。端末ごとに1回だけ必要です。

### iPhone・iPad
1. Safari で②の URL を開き、接続設定をします。
2. 共有ボタン →「ホーム画面に追加」→「追加」を押します。
3. ホーム画面の「家計簿」アイコンから開くと、Safari の枠のない普通のアプリとして起動します。

> iPhone では、Safari で設定した接続情報がホーム画面のアプリには引き継がれないことがあります。その場合は、アプリとして開いたあとにもう一度 URL とキーを入力してください。

### Windows（Edge / Chrome）
1. ②の URL を開き、接続設定をします。
2. アドレスバーの右にある「アプリをインストール」アイコン（⊕ や 🖥 の形）を押して「インストール」を選びます。
   - Edge は「…」→「アプリ」→「このサイトをアプリとしてインストール」からでもできます。
3. デスクトップやスタートメニューに「家計簿」ができ、専用のウィンドウで開きます。

### Android（Chrome）
1. ②の URL を開き、接続設定をします。
2. 「ホーム画面に追加」または「アプリをインストール」を押します。

## 使い方のメモ

- **同期**：アプリを開いたとき、別のアプリから戻ってきたとき、開いている間は1分ごとに最新のデータを読み込みます。右上の ⟳ で今すぐ読み込むこともできます。
- **オフライン**：電波がなくても、前回読み込んだ内容を見ることはできます。記録の保存は、電波のある所でしてください。
- **データの直接編集**：スプレッドシートの「tx」シートを直接直しても大丈夫です。ただし `id` 列は変えないでください。
- **接続先の変更**：右上の ⚙ から、URL とキーを入れ直せます。
- **アプリの更新**：GitHub のファイルを差し替えると、次に開いたときに新しい画面になります。
